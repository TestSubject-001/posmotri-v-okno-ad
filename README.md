# Посмотри в окно

Проектная работа курса «Вёрстка. Доступность и подходы к организации стилей» Яндекс Практикума.

## О проекте

«Посмотри в окно» — сервис поиска видео. В проекте свёрстаны:

- шапка с логотипом и ссылками на соцсети;
- поисковая форма с полем города и фильтрами по времени суток;
- карточки видео, прелоадеры и заглушки ошибок;
- состояния интерактивных элементов (`:hover`, `:active`, `:focus-visible`);
- доступная разметка и скрытые подписи для элементов формы.

## Технологии

HTML, CSS, JavaScript.
